# The Depot Motorworks Website

Static pre-launch website for The Depot Motorworks in Butler, Wisconsin.

## Files

- `index.html` — pre-launch homepage
- `jdm.html` — dedicated JDM page
- `css/styles.css` — site styling
- `js/main.js` — mobile navigation
- `images/` — site imagery

## Publish with GitHub Pages

1. Upload all files and folders to the root of the GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Save.

## Before launch

The newsletter form uses a placeholder Formspree URL:

`https://formspree.io/f/REPLACE_WITH_YOUR_FORM_ID`

Create a Formspree form and replace that value in `index.html` so submissions are delivered.

The site can be previewed by opening `index.html` in a browser.
